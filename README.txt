WFM（配送実績入力・PWA版 v3）

画面タイトルとホーム画面のアプリ名を「WFM」に変更しました。

入力項目
- 配送件数
- 個配件数
- ペア個配件数
- 実配件数
- 新規件数
- 班件数
- 班配布枚数
- 供給金額

GitHub Pagesへの反映手順
1. このフォルダ内のファイルとiconsフォルダを、GitHubリポジトリのルートへアップロードし、既存ファイルを置き換えます。
2. Settings > Pages > Deploy from a branch > main > /(root) を確認します。
3. 公開URLを開いて更新を確認します。キャッシュが残る場合は再読み込みし、ホーム画面に追加済みの場合は一度削除して再追加するとアプリ名も更新されます。

注意
- 記録は端末・ブラウザ内に保存され、端末間で同期されません。
- 社員番号ログインは簡易的な画面切替で、本人確認機能ではありません。
