トラックメモ（配送実績入力・PWA版 v2）

今回の入力項目
- 配送件数
- 個配件数
- ペア個配件数
- 実配件数
- 新規件数
- 班件数
- 班配布枚数
- 供給金額

GitHub Pagesへの反映手順
1. このフォルダ内のファイルとiconsフォルダを、GitHubリポジトリ truck-memo のルートへアップロードし、既存ファイルは置き換えます。
2. Settings > Pages > Deploy from a branch > main > /(root) が設定されていることを確認します。
3. 公開URLを開き、更新されていることを確認します。キャッシュが残る場合はページを再読み込みするか、少し時間をおいてください。
4. iPhoneはSafariの共有ボタン > ホーム画面に追加、AndroidはChromeメニュー > アプリをインストール（またはホーム画面に追加）。

注意
- 記録は端末・ブラウザ内に保存され、端末間で同期されません。
- 社員番号ログインは簡易的な画面切替で、本人確認機能ではありません。
- 過去バージョンで保存した記録は旧形式のため、新しい入力項目の集計対象では値が0になる場合があります。旧データ自体は自動削除しません。
