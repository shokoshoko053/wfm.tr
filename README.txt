トラックメモ（アプリ風/PWA版）

GitHub Pagesで公開する手順
1. このフォルダ内のファイル・iconsフォルダを、GitHubリポジトリのルートへすべてアップロードします。
2. Settings > Pages > Deploy from a branch > main > /(root) > Save を設定します。
3. 公開されたHTTPSのURLをスマホで開きます。
iPhone: Safariの共有ボタン > ホーム画面に追加 > 追加
Android: Chromeのメニュー > アプリをインストール（またはホーム画面に追加）

注意
- PWAのインストールとオフラインキャッシュにはHTTPSでの公開が必要です。GitHub Pagesなら通常HTTPSになります。
- 記録データは元のHTMLと同様に端末のブラウザ内に保存され、端末間では同期されません。ブラウザのデータ消去で失われる可能性があるため、実運用前に確認してください。
- これはアプリストア配布用のネイティブアプリではなく、ホーム画面に追加して使うWebアプリです。
